# RepoReel

**Describe what you're building. Get the right GitHub repo, and the reel that shows it working.**

RepoReel keeps a trusted, continuously refreshed catalog of GitHub repositories and links each one to reels from vetted creators that explain it. Ask in plain language; get 3–5 repos with reasons, health and momentum, plus the best creator reel for each as proof.

- 📄 [Product & technical spec](docs/SPEC.md)
- 🎨 [Design system](docs/DESIGN.md) (Apple-inspired, adapted from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md))

Status: specification, v0.1. Not affiliated with Apple, Meta or Instagram. Uses official Instagram embeds and APIs only; no scraping.
